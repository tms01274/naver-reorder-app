# 재고 발주 도우미

네이버 스마트스토어 판매 속도를 기준으로 재고가 소진되기 전에 발주해야 할 품목을 알려주고,
품목 상세 정보를 확인한 뒤 버튼 한 번으로 발주 메일을 작성할 수 있는 로컬 웹앱입니다.

## 0. Windows에서 가장 쉬운 방법 (추천)

터미널 명령어를 몰라도 됩니다. `설치하기.bat` 파일을 더블클릭하면:
Node.js가 없으면 설치 페이지를 열어주고, 있으면 자동으로 설치 → 설정파일 생성 →
컴퓨터 켤 때마다 자동 실행되도록 등록 → 지금 바로 실행 → 브라우저까지 자동으로 열어줍니다.
바탕화면에는 **"재고 발주 도우미" 아이콘 하나**가 생깁니다. 평소에는 이것만 누르면 됩니다.
누를 때마다 새 버전이 있으면 자동으로 받아 적용하고(인터넷이 안 되면 건너뜀), 서버가 꺼져
있으면 켠 다음 화면을 엽니다. 서버는 창 없이 실행되므로 실수로 닫힐 일도 없습니다.
(동작 기록: `data\launcher-log.txt`, 서버 로그: `data\server-log.txt`)

나중에 `.env` 파일(네이버 API 키 등)을 고친 뒤에는 바탕화면 아이콘을 누르면 됩니다. 서버가 켜진 뒤에
`.env` 가 바뀐 것을 알아채고 자동으로 재시작해서 반영합니다.

### 새 버전으로 업데이트하기

바탕화면 아이콘을 누르면 자동으로 업데이트됩니다. 수동으로 하고 싶으면 `업데이트.bat`을
더블클릭해도 됩니다(최신 코드 받기 → 부품 설치 → 재시작).
예전 버전으로 설치된 PC는 한 번만 업데이트되면, 서버가 켜질 때 바탕화면 아이콘이 새 아이콘
하나로 자동으로 바뀝니다(예전 "열기"/"업데이트" 아이콘은 지워짐). `.env` 설정과 `data` 폴더(공급업체 정보, 로그)는
전혀 건드리지 않으니 안심하고 눌러도 됩니다.

이 프로그램은 GitHub **공개** 저장소(`https://github.com/tms01274/naver-reorder-app`)로
관리되므로 코드를 받을 때 토큰이나 로그인이 필요 없습니다. (비공개로 바꾸면 매장 PC의 자동
업데이트가 멈추니 주의하세요. API 키 등 비밀값은 `.env`에만 두고 저장소에 올리지 않습니다.)
**PC 를 바꿀 때(매장)**: 새 PC 에 구글 드라이브를 설치·로그인 → 구글 드라이브 `아틀리에말리 백업` 폴더의
`새PC-설치하기.bat` 더블클릭 → 열리는 '새 PC 설정' 창에서 백업 가져오기 → 관리자가 같은 창에서 네이버 API 키 입력.
(매일 자동 백업이 구글 드라이브에도 들어가고, 설치 파일도 그 폴더에 자동으로 놓입니다.)

다른 PC/지점에 처음 설치할 때(수동)는 아래 순서로 진행하세요.

1. Git 설치: `winget install --id Git.Git -e` (끝나면 PowerShell 을 닫고 새로 열기)
2. 코드 받기: `git clone https://github.com/tms01274/naver-reorder-app.git C:\naver-reorder-app`
3. 받은 폴더 안에서 `설치하기.bat` 더블클릭 → 이후로는 바탕화면 아이콘만 누르면 자동 최신화

사용법은 `docs/아틀리에말리-사용설명서.docx` (화면 캡처가 들어간 Word 설명서)를 참고하세요.

아래는 터미널로 직접 하고 싶을 때(개발/Mac 등)를 위한 수동 설치 방법입니다.

## 1. 처음 실행하기 (샘플 데이터로 바로 체험)

```bash
cd naver-reorder-app
npm install
cp .env.example .env
npm start
```

브라우저에서 `http://localhost:3000` 접속하면 바로 샘플 상품 5개로 화면을 확인할 수 있어요.
(`.env`에 `MOCK_MODE=true`가 기본값이라 API 키 없이도 동작합니다)

화면에서 할 수 있는 것:
- 왼쪽에서 판매속도 계산 기간 / 안전 여유일수 조정
- 발주가 필요한 품목이 상단에 자동으로 표시됨
- 품목 클릭 → 상세 정보 + 공급업체명/이메일 입력 및 저장
- 입고유형 라벨(예: 국내/수입)을 만들어 품목마다 지정하면, 그 라벨의 리드타임이 발주 계산에 자동 반영됨 ("입고유형 라벨 관리"에서 관리)
- **발주 메일 작성하기** 버튼 → 기본 메일 앱이 열리고 품목/수량/재고 정보가 채워진 메일이 준비됨 (전송은 직접 클릭)

## 2. 실제 네이버 데이터 연동하기

### 2-1. 커머스API 애플리케이션 발급
1. https://apicenter.commerce.naver.com 접속 후 스마트스토어 판매자 계정으로 로그인
2. **내 스토어 애플리케이션** 메뉴에서 애플리케이션 등록
3. 발급된 `client_id`, `client_secret`을 `.env` 파일에 입력
4. `.env`에서 `MOCK_MODE=false` 로 변경

```
MOCK_MODE=false
NAVER_CLIENT_ID=발급받은값
NAVER_CLIENT_SECRET=발급받은값
```

5. 바탕화면 아이콘을 누르면 자동으로 재시작돼 반영됩니다 (또는 터미널에서 `npm start`)

### 2-2. 반드시 확인해주세요 (중요)

네이버 커머스API의 **상품/재고 조회**, **주문 내역 조회** API는 세부 경로와 필드명이
가끔 바뀝니다. `src/naverClient.js` 파일 상단의 `API_ENDPOINTS`와, `fetchProducts` /
`fetchRecentOrders` 함수 안의 필드 매핑 부분(`channelProduct.stockQuantity` 등)을
아래 공식 문서와 비교해서 한 번만 확인해주세요.

- 공식 문서: https://apicenter.commerce.naver.com/ko/basic/commerce-api
- 기술 Q&A: https://github.com/commerce-api-naver/commerce-api/discussions

만약 API 호출이 실패하면 **터미널 콘솔에 네이버가 보낸 에러 메시지가 그대로 출력**됩니다.
(예: 파라미터 누락, 필드명 오류 등) 에러 메시지에 원인이 대부분 나와있어서,
그 문구를 문서에서 검색하면 어디를 고쳐야 하는지 바로 알 수 있어요.
인증(토큰 발급) 부분은 공식 규격 그대로 구현되어 있어서 보통은 건드릴 필요가 없습니다.

> 참고: 내 스토어 애플리케이션은 초당 2회 호출 제한이 있습니다. 실시간 동기화보다는
> 화면을 열 때마다(또는 하루 몇 차례) 새로고침하는 정도로 쓰는 걸 권장합니다.

## 3. 발주 메일 양식 직접 작성하기

왼쪽 설정 패널의 **발주 메일 양식 관리**를 펼치면 제목/본문을 원하는 문구로 직접 작성할 수 있습니다.
`{{품목명}}`, `{{수량}}`, `{{재고}}`, `{{일평균판매}}`, `{{소진예상}}`, `{{업체명}}` 을 원하는 위치에
넣으면 발주 메일 작성 시 실제 값으로 자동 치환됩니다. **양식 저장** 버튼을 누르면 계속 저장돼서,
다음에 켤 때도 그대로 유지됩니다.

## 4. 컴퓨터 껐다 켜도 자동으로 실행되게 하기 (Windows)

`설치하기.bat`을 실행했다면 이미 설정되어 있습니다 (위 "0번" 참고). Windows의 **시작프로그램**
폴더에 최소화 바로가기를 등록하는 방식이라, 로그인할 때 창이 잠깐 보였다가 작업표시줄로
최소화됩니다 (완전히 숨기는 방식은 백신 소프트웨어가 의심할 수 있어 일부러 이렇게 했습니다).

수동으로 등록/해제하고 싶으면 `windows-autostart` 폴더 안의 `install-autostart.bat` /
`uninstall-autostart.bat`을 따로 실행하면 됩니다.

(Mac에서는 `pm2` 사용: `npm i -g pm2` → `pm2 start server.js` → `pm2 startup` → `pm2 save`)

## 5. 나중에 자동 새로고침이나 알림(카톡/문자 등)이 필요하면

지금은 "화면을 열면 최신 데이터를 보여주는" 방식입니다. 매일 아침 자동으로
발주 필요 품목을 알림으로 받고 싶다면, 이 서버에 스케줄러(예: node-cron)를 추가해서
정해진 시간마다 `/api/products`를 조회하고 필요시 알림을 보내는 기능을 이어서 만들 수 있어요.
